**Required correction:** select presence/type rules consistent with the native string branch, state invalid-type handling and keep the reason string out of serialized content. ### F2 — Major — Select the companion message integration with the root protocol

**Traceability:** S9-B-2 (Major). [Full source comparison](implementation_readiness_report.md).

VW defines exact v/kind/viewId wire messages and forbids extra keys. The pinned root HostMessage/WebviewMessage unions, decoders and consumers use type. The plan does not select wrapping, translation, separate narrowing or another exact compatible representation. Literal addition of kind-only variants to the current root unions would invalidate existing .type reads; passing exact VW messages through the unchanged decoder would reject them. These are conditional static consequences, not a compiler or runtime failure observed here. [Closed VW envelope](https://github.com/glitchwerks/vscode-claude-workspaces/blob/feef3a2995e679b4ab56785aad2fb81e0d298656/docs/designs/215/companion-view-contract.md#L9-L11), [field closure](https://github.com/glitchwerks/vscode-claude-workspaces/blob/feef3a2995e679b4ab56785aad2fb81e0d298656/docs/designs/215/companion-view-contract.md#L43-L69), [pinned root protocol](https://github.com/glitchwerks/vscode-claude-workspaces/blob/ef5fd48f4b676881a8730afbf8e583e70565ca11/src/panel/protocol.ts#L30-L118).

**Required correction:** specify the wire-to-root decoder/type representation and narrowing before dispatch. Reconcile the current write boundary with all consumers, including integration lifecycle/terminalDiagnostics and the manual terminalEchoWebview harness; add paths only if the selected integration requires changing them. Pin root-decoder round-trip/rejection and legacy-consumer compatibility expectations. [Provider dispatch](https://github.com/glitchwerks/vscode-claude-workspaces/blob/ef5fd48f4b676881a8730afbf8e583e70565ca11/src/panel/sessionPanelProvider.ts#L400-L445), [lifecycle helper](https://github.com/glitchwerks/vscode-claude-workspaces/blob/ef5fd48f4b676881a8730afbf8e583e70565ca11/test/integration/lifecycle.test.ts#L629-L645), [diagnostics helper](https://github.com/glitchwerks/vscode-claude-workspaces/blob/ef5fd48f4b676881a8730afbf8e583e70565ca11/test/integration/terminalDiagnostics.test.ts#L296-L340), [manual consumer](https://github.com/glitchwerks/vscode-claude-workspaces/blob/ef5fd48f4b676881a8730afbf8e583e70565ca11/test/manual/terminalEchoWebview.ts#L52-L62), [phase allowlist](https://github.com/glitchwerks/vscode-claude-workspaces/blob/feef3a2995e679b4ab56785aad2fb81e0d298656/docs/designs/215/design_draft.md#L236-L243).

**Traceability:** S9-B-3 (Major). [Full ownership comparison](implementation_readiness_report.md).

**Required correction:** pin exact keys/types/byte cap, host/channel/generation identity, validation and cleanup authorization. Filesystem admission/deletion risks remain inferred, with no ACL or cleanup incident observed. [Selected precedent limitation](https://github.com/glitchwerks/vscode-claude-workspaces/blob/feef3a2995e679b4ab56785aad2fb81e0d298656/docs/designs/215/technical_choices.md#L160-L165), [reviewer rationale](implementation_readiness_report.md).
