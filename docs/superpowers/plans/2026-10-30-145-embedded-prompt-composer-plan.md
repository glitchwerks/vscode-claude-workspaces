## Review Focus

1. **A busy Claude session or permission dialog:** composer Ctrl+Enter must normally queue, never interrupt work or answer a dialog. Pin this in Tasks 1, 3, and 8. [S:L113-L139; E1]
2. **A late acknowledgment after new typing, resume, or Forget:** preserve newer text, reject the old generation, and never recreate deleted state. Pin this in Tasks 2 and 4. [S:L65-L83,L113-L119]
3. **IME input, Unicode, clipboard, and competing keybindings:** composition Enter must not send; output/status events must not pull focus away. Pin this in Tasks 5 and 8. [S:L49-L63]
4. **A draft with no saved conversation, or a failed storage write:** make recovery discoverable and never label unsaved text Saved. Pin this in Tasks 2, 4, and 8. [S:L65-L83]
5. **File exclusions, symlink escapes, hostile preview text, and stale command lists:** do not broaden directory access, execute markup, or substitute an invocation. Pin this in Tasks 6 and 7. [S:L85-L111]

## Shared interface decisions

Implement these in Task 2; Task 1's probe uses a local fixture shape and must converge on them. Names here are planning contracts, not claims that symbols already exist. The numeric bounds are **author-selected planning defaults** for the spec's bounded extras and payloads, not measured performance budgets. [S:L95-L111,L115-L139]

```ts
type ComposerTarget = Readonly<{
  sessionId: string; claudeSessionId: string; generation: string;
}>;
type ComposerCapability =
  | Readonly<{ status: 'available'; target: ComposerTarget }>
  | Readonly<{ status: 'unavailable'; sessionId: string; generation: string;
      reason: 'unsupported-identity' }>;
type ComposerLayout = Readonly<{ splitRatio: number }>;
type RecoveryDraftRow = Readonly<Pick<SavedComposerSession,
  'claudeSessionId' | 'rootId' | 'rootPath' | 'displayName'> & { draftRevision: number }>;
type RecoveryCursor = Readonly<{ revision: number; afterUuid: string }>;
type RecoveryPage = Readonly<{
  revision: number; rows: readonly RecoveryDraftRow[]; nextCursor?: RecoveryCursor;
}>;
type DraftState = Readonly<{
  revision: number; text: string;
  selection: Readonly<{ anchor: number; head: number }>;
}>;
type SavedComposerSession = Readonly<{
  claudeSessionId: string; rootId: string; rootPath: string; displayName: string;
  draft: DraftState; recent: readonly string[];
}>;
type ComposerCommand = Readonly<{
  invocation: string; description: string; source: string; plugin?: string;
}>;
type SubmitRequest = Readonly<{
  target: ComposerTarget; submissionId: string; draft: DraftState;
}>;
type SubmitResult =
  | Readonly<{ status: 'accepted'; submissionId: string; revision: number }>
  | Readonly<{ status: 'rejected'; submissionId: string;
      reason: 'unavailable' | 'dialog' | 'terminal-draft' | 'invalid' }>
  | Readonly<{ status: 'unconfirmed'; submissionId: string }>;
type SaveResult = 'saved' | 'stale' | 'forgotten' | 'too-large' | 'failed';
interface ClaudeComposerAdapter {
  listCommands(target: ComposerTarget): Promise<readonly ComposerCommand[]>;
  submit(request: SubmitRequest): Promise<SubmitResult>;
  disposeSession(target: ComposerTarget): Promise<void>;
}
```

`ComposerTarget` is constructed only after host validation of a canonical UUID and current live generation. Host selection accepts live IDs without assuming a durable identity: `select(sessionId: string, generation: string): Promise<ComposerCapability>`. An unavailable result never creates/loads a saved composer record, enables submit, or substitutes a PTY ID for the missing UUID; direct-terminal use remains available. Gate adapter calls and every draft/send intent against current capability, including stale available messages after capability loss. [S:L65-L83; R8; PR #197]

Constants: `COMPOSER_STATE_KEY = "claudeWorkspaces.composerState"`, schema version `1`, `MAX_DRAFT_UTF8_BYTES = 1_048_576`, `RECENT_MAX_ITEMS = 20`, `RECENT_MAX_UTF8_BYTES = 262_144`, `FILE_RESULT_LIMIT = 100`, `SAVE_DEBOUNCE_MS = 200`, `CATALOG_TIMEOUT_MS = 2_000`, `SUBMIT_ACK_TIMEOUT_MS = 5_000`, `SPLIT_RATIO_MIN = 0.15`, `SPLIT_RATIO_MAX = 0.75`, `RECOVERY_PAGE_LIMIT = 100`. Split bounds and recovery page size are author-selected validation defaults; the ratio is the normal composer fraction of the session column. Never truncate a draft to fit a bound: retain editable text, reject the oversized save/send explicitly, and keep Saved false. Oversized accepted prompts need not enter the bounded recent list. [S:L65-L111]

Protocol intents: browser `composerLayoutChanged`, `composerRequestRecovery`, `composerRestoreDraft`, `composerDraftChanged`, `composerSubmit`, `composerRequestCatalog`, `composerPickFile`, `composerHistorySelected`, `composerFavoriteChanged`, `composerFocusChanged`; host `composerLayoutStatus`, `composerRecoveryInvalidated`, `composerRecoveryPage`, `composerHydrate`, `composerDraftStatus`, `composerSubmitResult`, `composerCatalog`, `composerInsertText`, `composerFocus`. Use exact-key codecs. Browser targets carry only IDs/generation, never filesystem paths or executable arguments. Definitions and decoder assertions belong in Task 4. [R1; S:L115-L139]

Exact payload decisions for Task 4 (all add a literal `type`): draft change `{ target, draft }`; submit `{ request: SubmitRequest }`; catalog/file request `{ target, requestId }`; history selection `{ target, index, mode: 'replace' | 'append', expectedRevision }`; favorite change `{ target, invocation, enabled }`; focus report `{ target, documentId, focused, pickerFocused }`. Host hydration is discriminated by `capability.status`: available `{ capability: { status: 'available', target }, session: SavedComposerSession, visible, layout: ComposerLayout, favorites, canSubmit: boolean }`; unavailable `{ capability: { status: 'unavailable', sessionId, generation, reason }, visible, layout: ComposerLayout, favorites, canSubmit: false }`, with no `session` or fabricated durable target in the unavailable branch; draft status `{ target, revision, status: 'saving' | 'saved' | 'error' | 'too-large' }`; submission result `{ target, result: SubmitResult }`; catalog `{ target, requestId, commands, status: 'ready' | 'unavailable' }`; insert `{ target, requestId, expectedRevision, text }`; focus `{ target, documentId, destination: 'editor' | 'terminal' }`. Add host `composerAction` with `{ target, documentId, action: 'submit' | 'toggle' | 'pickCommand' | 'find' | 'replace' | 'undo' | 'redo' }` so native VS Code commands can address the webview without a second hard-coded browser keymap. UUID/generation/request/document IDs are canonical UUIDs; live IDs are nonempty strings. Revisions and indexes are bounded nonnegative safe integers. Validate selection offsets against the corresponding text. [S:L65-L139; R1]

Workspace layout intent `composerLayoutChanged` carries `{ documentId, splitRatio }`, independently of any durable session target. The host derives workspace ownership from its panel, verifies the current document, and accepts only finite ratios within the declared bounds. `ComposerController.updateLayout(documentId, layout: ComposerLayout): Promise<'saved' | 'failed'>` writes through `ComposerStore.setLayout(layout): Promise<void>`; `getLayout(): ComposerLayout` returns the validated persisted ratio or the one-third default. Host `composerLayoutStatus` carries `{ documentId, layout, status: 'saved' | 'error' }`; failed writes cannot be reported saved. Serialize layout writes, reject stale documents, and hydrate from host storage on reload. [S:L47-L51; R1; R3; PR #197]

`ComposerStore.recoveryPage(cursor?: RecoveryCursor): RecoveryPage` exposes at most `RECOVERY_PAGE_LIMIT` immutable metadata rows for nonempty drafts, ordered by canonical UUID, without draft/history text. `readonly onDidChangeRecovery: vscode.Event<void>` invalidates consumers after successful save/transfer/Forget changes. Cursors are host-issued and snapshot-revision-bound; reject a stale cursor and restart enumeration rather than skip rows. Paging bounds messages and reads without deleting or silently hiding persisted drafts. On startup and change, the provider reads pages, merges with eligible resumables by UUID, and excludes live UUIDs; eligible rows keep Resume, while draft-only rows expose Restore draft. Reuse `forgetSession` to remove both stores and invalidate recovery rows, with tombstones preventing late callbacks from restoring them. [S:L65-L83; R8; PR #197]

Browser `composerRequestRecovery` carries `{ documentId, requestId, cursor?: RecoveryCursor }`; host `composerRecoveryPage` carries `{ documentId, requestId, page: RecoveryPage, actions: readonly ('resume' | 'restoreDraft')[] }`, with one action per returned row derived from host eligibility. `composerRecoveryInvalidated` carries `{ documentId, revision }` and restarts the bounded snapshot after store, eligibility, or live-session changes; discard stale pages. Browser `composerRestoreDraft` carries `{ documentId, claudeSessionId, expectedRevision }`; `restoreDraft(uuid, expectedRevision): Promise<void>` validates the current stored record, excludes live UUIDs, and revalidates its host-owned root before launch/transfer. Provider view generations additionally invalidate in-flight page replies when eligibility or live-session membership changes without a store write; store revisions alone cannot detect those changes. Browser cursors and IDs never authorize arbitrary roots or bypass tombstones. [R1; R3; R8; S:L81-L83]
