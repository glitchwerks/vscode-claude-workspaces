# Promote 0.5.2 to 0.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote the validated `v0.5.2` product tree to the Marketplace stable channel as `0.6.0` without adding runtime behavior.

**Architecture:** The release branch starts at the immutable `v0.5.2` commit and changes only release-contract tests, package metadata, the changelog, and channel documentation. Tests move the repository contract from odd-minor pre-release to even-minor stable before the metadata changes, proving that the promotion is the only behavior under test. [Issue #116](https://github.com/glitchwerks/vscode-claude-workspaces/issues/116)

**Tech Stack:** TypeScript 6, Node.js release scripts, Mocha, npm, VS Code Extension packaging.

**Spec:** [Issue #116](https://github.com/glitchwerks/vscode-claude-workspaces/issues/116)

## Global Constraints

- The candidate begins at `v0.5.2`, commit `65d26f2`, whose publication workflow succeeded on 2026-09-17. [Issue #116](https://github.com/glitchwerks/vscode-claude-workspaces/issues/116), [workflow run 35168007041](https://github.com/glitchwerks/vscode-claude-workspaces/actions/runs/35168007041)
- The promotion commit must not modify runtime product code. [Issue #116](https://github.com/glitchwerks/vscode-claude-workspaces/issues/116)
- Even minor versions use the stable packaging channel, while odd minor versions use the pre-release channel. `docs/versioning-policy.md:L45-L58`
- The final release notes must preserve the ruling that issue #56 remains unresolved after the 0.5.1 renderer experiment. `CHANGELOG.md:L38-L42`, [Issue #56 ruling](https://github.com/glitchwerks/vscode-claude-workspaces/issues/56#issuecomment-5706077187)
- Pushing `v0.6.0` after merge runs the validation, Marketplace publication, and GitHub Release workflow. `docs/versioning-policy.md:L63-L68`
- The promotion PR targets `main`, identifies PR #115 and commit `65d26f2` as its validated source, and relates to issue #116 without closing it before publication. [Issue #116](https://github.com/glitchwerks/vscode-claude-workspaces/issues/116), [PR #115](https://github.com/glitchwerks/vscode-claude-workspaces/pull/115)
